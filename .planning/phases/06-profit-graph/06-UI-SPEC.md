## Layout and Placement

**Visual hierarchy:** the headline totals are read first, then the green extracted line (drawn on top of the grey line); the range picker and Hide/Show are secondary controls.

- Mounts at the very top of `OpportunitiesScreen.tsx`, above the sport chips and the feed (D-11). One card, full width of the content column.
- Card shell matches ProfitSummary: `rounded-lg border border-border bg-secondary p-4`, children separated by `gap-2` (8px) inside the card, `gap-4` between header block and chart.
- Header block (top to bottom):
  1. Row 1: headline totals (left, wraps) and Hide control (right, `ml-auto`).
  2. Row 2: range picker (`toggle-group`, single select, 3 items), full width on phones, auto width from `sm` up.
- Chart area: fixed `height: 160px` (D-11), `width: 100%`, wrapper has `touch-action: pan-y` so vertical page scroll still works while a horizontal drag scrubs the tooltip.
- Mobile first: at 360px width the header wraps (headline on its own line, Hide control stays top-right, range picker below). No horizontal scroll at any width.
- Loading (response not yet received): `skeleton` of the same footprint (headline line 20px high, picker 36px high, chart block 160px) so the feed does not jump.
- Hidden state (D-12): only Row 1 remains, with the headline hidden too. The card collapses to a single 44px-high row showing the title "Profit graph" and a "Show graph" button. Remembered per device.

## Typography

Exactly 3 sizes and 2 weights (existing app values: text-xs, text-sm, text-lg).

| Role | Size | Weight | Line Height |
|------|------|--------|-------------|
| Body / labels / picker / button text (`text-sm`) | 14px | 400 regular (600 where noted) | 1.5 |
| Axis ticks, tooltip date and gain line, caption (`text-xs`) | 12px | 400 | 1.5 |
| Headline totals (`text-lg`, `num` class on the dollar figures) | 18px | 600 semibold for the two dollar figures, 400 for the surrounding words | 1.2 |

Weights: 400 and 600 only. (Do not use `font-medium` in this component.) Tooltip total figures use 14px at 600; the tooltip date uses 12px at 400 in `text-muted-foreground`.

## Color

Uses the existing tokens only; both light and dark come free through `prefers-color-scheme` (OS preference only, no toggle). No new CSS variables.

| Role | Value | Usage |
|------|-------|-------|
| Dominant (60%) | `--background` (white / oklch 0.145) | Page |
| Secondary (30%) | `--secondary` (oklch 0.97 / 0.269) | The graph card surface (same as ProfitSummary) |
| Accent (10%) | `--primary` (#059669 light, #10b981 dark) | Green extracted line, the extracted dollar figure in the headline, the extracted figure in the tooltip, the standard focus ring (`--ring`, same green) |
| Grey line | `--muted-foreground` (oklch 0.556 light, 0.708 dark) | Available line, the available dollar figure in the headline, the available figure in the tooltip |
| Destructive | `--destructive` | Not used in this phase (no destructive actions) |

Accent reserved for: the green extracted line, the extracted dollar figure in the headline, the extracted figure in the tooltip, and the standard focus ring. The selected range item uses `--foreground` on `--background` (existing toggle-group pressed style), NOT green, so green keeps meaning "extracted".

Line styling:
- Both lines: `type="stepAfter"` (step, since data is daily), `strokeWidth` 2, no dots (`dot={false}`), animation off.
- Green drawn on top of grey so the extracted line is never hidden when they overlap.
- Active dot on hover/touch: 4px radius filled with the line color, ring 2px `--secondary`.
- Cursor (vertical hover line): 1px `--border` colored `stroke`, not dashed.
- Axes: no axis lines, no grid lines except one faint horizontal baseline at $0 (`--border`). Tick text 12px `--muted-foreground`.
- Meaning must not rely on color alone: a two-item legend with a swatch is built into the headline (see copy), and the grey line is drawn solid while green is solid and heavier-weighted on top; headline words "Extracted" and "available" name the lines.
- Contrast: grey #-equivalent against `--secondary` passes 3:1 for graphics in both modes; executor verifies green and grey in dark mode during the phone check.

Axes details:
- X axis: Denver dates, at most 4 ticks on phones (`interval="preserveStartEnd"`, `minTickGap` 48), format `Oct 3` (short month, day, no year). Ticks derive from the server's `today` string, never the client clock.
- Y axis: hidden (the headline and tooltip carry exact numbers), domain `[0, auto]`. To keep a scale reference, show a single right-aligned label for the top value only if it fits; otherwise omit. (Default: omit.)
- Series starts with a $0 anchor point on the day before the range's first day (or on the graph start day itself when the range is clamped) so both lines visibly start at $0 (D-01, D-04 revised).

## Interaction Contract

| Interaction | Behavior |
|-------------|----------|
| Hover (desktop) / touch and drag (phone) | Tooltip at the pointer/finger, snapping to the nearest day; vertical cursor line; active dots on both lines (D-14, D-15) |
| Release / mouse leave | Tooltip disappears; headline shows end-of-range totals again (D-16). The headline never changes while scrubbing |
| Range picker | Single-select toggle group. Tapping the already-selected item does nothing (ignore empty value). Change is instant, no refetch (slice computed client-side), remembered per device, default "Last 30 days" (D-03) |
| Hide / Show | Button toggles the chart and picker; state remembered per device (D-12). Keyboard accessible, `aria-expanded` set |
| Range clamp | If the graph start day is later than the range start, the chart simply begins on the graph start day (no padding days, no estimates) |
| Keyboard | Range picker arrow keys per toggle-group; chart itself is not focusable. For screen readers, the chart wrapper has `role="img"` and an `aria-label` equal to the headline plus range label (see copy) |
| Reduced motion | No chart animation at all (always off) |

## Copywriting Contract

Plain English, no jargon. All dollar figures use `formatUsd` (exact to the cent, from decimal strings). Dates are Denver days.

| Element | Copy |
|---------|------|
| Card title (shown when hidden, and as the accessible name) | Profit graph |
| Headline (D-13) | `Extracted $123.45 of $210.00 available` ("Extracted" and the first figure in green and semibold; "available" figure in grey and semibold; "of" regular in `--foreground`). Figures are end-of-range totals for the selected range |
| Headline accessible label | `Extracted $123.45 of $210.00 available, Last 30 days` |
| Range picker labels | `Last 7 days` / `Last 30 days` / `All time` |
| Hide control (chart showing) | `Hide graph` (with lucide `ChevronUp`, 16px) |
| Show control (chart hidden) | `Show graph` (with lucide `ChevronDown`, 16px) |
| Tooltip line 1 (date) | `Fri, Oct 3` (weekday short, month short, day) |
| Tooltip line 2 | `Available so far` then `$210.00` (grey swatch) |
| Tooltip line 3 | `Extracted so far` then `$123.45` (green swatch) |
| Tooltip line 4 (that day's gain) | `That day: +$12.40 available, +$8.00 extracted` (12px, muted; uses `+$0.00` when nothing that day) |
| Empty state heading (D-17, no history in the selected range) | `Nothing yet` |
| Empty state body | `Once you have profit to take or you mark a promo done, your lines will show up here.` (the chart area is replaced by this text, centered, in the same 160px height; range picker stays usable; headline shows `Extracted $0.00 of $0.00 available`) |
| Before the new table has any data (first release day, no member rows yet and no completions) | Same empty state heading `Nothing yet`; body: `The graph starts today. Come back tomorrow to see your first line.` |
| Before the migration is applied (new table missing; read falls back gracefully) | Same card, no error styling: heading `Graph not ready yet`; body: `The graph is being set up and will appear once setup finishes. Your totals elsewhere are not affected.` Not a red error, no retry button (nothing the member can do) |
| Series failed to load (unexpected error, response has no series) | Heading `Couldn't load the graph`; body: `Your opportunities below are fine. Refresh the page to try again.` Text only, uses `--muted-foreground` (not destructive) |
| Caption under chart (always, when chart shown) | `Each promo counts once, on the day it first showed up, at the best profit it reached.` (12px, muted). Plain-English version of D-08 |
| Primary CTA | None. The phase adds no primary action (Hide graph / Show graph is a secondary text button) |
| Destructive actions | None in this phase. Undo of Mark done is existing behavior elsewhere and is out of scope |

Empty-state rule: show "Nothing yet" when no day in the selected range has a nonzero available or extracted gain. If either line has data, draw the chart (a flat line at $0 for the other is fine).

## Assumptions (not owner-confirmed)

The owner locked D-01..D-18. These choices are defaults for review:

1. Type scale: 12 / 14 / 18 px with weights 400 / 600 (the app elsewhere uses 500 medium; dropped here to hold to two weights).
2. Grey is the app's `--muted-foreground`, green is the app's `--primary` (research recommended both; dark-mode contrast to be checked on a device).
3. Y axis hidden, only a $0 baseline; exact numbers come from the headline and tooltip.
4. A $0 anchor point is drawn one day before the first day so both lines clearly start at $0 (research recommended yes).
5. Header layout: headline on top, range picker on its own row, Hide/Show at top right (CONTEXT left this to discretion).
6. Hidden state shows a slim one-row card ("Profit graph" plus "Show graph") rather than disappearing, so the owner can always get it back.
7. All copy not quoted in CONTEXT.md: tooltip wording, "Nothing yet" body text, the "graph starts today" message, "Graph not ready yet", "Couldn't load the graph", and the caption under the chart. The caption restates D-08 in plain English and could be dropped if the owner thinks it is clutter.
8. No on-chart estimate caption is needed, because D-04 (revised) has no estimated days; days before the graph start day are simply not drawn.
9. Touch target minimum of 44px for picker and Hide/Show.
10. X-axis label format `Oct 3`, at most 4 ticks on phones.
