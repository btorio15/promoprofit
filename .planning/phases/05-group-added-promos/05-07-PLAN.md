<objective>
Phase goal (user story):

**As a** group member, **I want to** add a promo I see in my own sportsbook app and manage the ones I added, **so that** my Promos list and Opportunities feed include the promos the scrapers miss, with the same exact hedge math, visible only to me.

Management slice (part 2): a member taps Edit on their added promo, gets the same form prefilled, changes terms/games/caps/expiry, saves, and the promo updates in place in Promos and Opportunities.

Purpose: PROMO-05 (edit), D-10.
Output: shared server validation pipeline, editPromo action, prefill via the options action, form edit mode + Edit button.
</objective>
