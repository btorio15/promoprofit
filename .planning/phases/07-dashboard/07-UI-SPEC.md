## Layout and Placement

**Visual hierarchy:** the Extracted all-time figure is the focal point of the totals card (first in reading order, green). The other three totals are equal-weight secondary figures. The graph card and feed follow unchanged.

Vertical order inside the Dashboard panel (`flex flex-col gap-8`, as today):
1. Header: `h1` "Dashboard" + subtitle (D-13).
2. Totals card (new component, e.g. `DashboardTotals.tsx` in `src/components/opportunities/`; replaces `ProfitSummary`, which is removed from this screen).
3. Profit graph card (existing `ProfitGraph`, unchanged except its headline range framing, see Copywriting).
4. Stale-odds warning line (existing, unchanged).
5. "Opportunities" section heading (D-14), then `SortSwitch`, then the feed (existing).

**Totals card shell:** same as ProfitSummary and the graph card: `rounded-lg border border-border bg-secondary p-4`, inner `gap-4`.

**Totals grid:**
- Phone (<640px): 2 x 2 grid (`grid grid-cols-2 gap-x-4 gap-y-4`). Row 1: Extracted all-time | Available since Oct 13. Row 2: Last 7 days | Last 30 days (D-08).
- From `sm` up: one row of four (`sm:grid-cols-4`), `gap-x-8`.
- Each total cell: label (14px muted) above value (18px semibold, `num`). The two "last N days" cells show a second muted 12px line under the value: `of $X available` (D-03), so the cell reads e.g. value `$10.79`, caption `of $2.56 available`. Cells have `min-w-0` so a 7-digit value never overflows at 360px.
- Counts line: below a `border-t border-border pt-4` divider, one wrapping line of 14px muted text (`text-sm text-muted-foreground`), items separated by ` · `, dollar figures in `num` and foreground color. On phone it wraps naturally to at most 2 lines; the best-promo name is truncated (`truncate` on a `min-w-0` span, max one line) so the line never grows past two lines.
- Total card height target on a 360px phone: at most about 200px, so the first opportunity row is visible with the graph hidden and begins within one scroll with it shown (success criterion 5). Do not add a caption or footnote paragraph under the counts (the old ProfitSummary footnote is dropped).

**Loading:** while `showSkeleton`, render a `Skeleton` of the same footprint (two 40px rows on phone, divider, one 20px line) so the feed does not jump.

**Graph hide (D-07):** the totals card is never hidden or collapsed. Hide graph affects only the graph card; the existing collapsed "Profit graph" bar with the "Show graph" button remains the way back.

**Tab bar (AppShell):** labels in order Dashboard, Stats, Arbitrage, Promos, Tools. Triggers keep `min-h-11 whitespace-nowrap`. Home tab internal id may stay `opportunities`; the teammate's tab id becomes `stats` (D-15). "Dashboard" is 9 characters (vs "Opportunities" 13), so the bar fits no worse than today; the existing horizontal-scroll behavior of the tab list stays as the fallback. Verify at 360px that all five are reachable.

## Typography

Exactly 4 sizes and 2 weights (all already in use in the app).

| Role | Size | Weight | Line Height |
|------|------|--------|-------------|
| Caption (`text-xs`): "of $X available" under 7d/30d values | 12px | 400 | 1.5 |
| Body / labels / counts line (`text-sm`) | 14px | 400 | 1.5 |
| Totals values (`text-lg`, `num`) | 18px | 600 | 1.2 |
| Page heading `h1` (`text-xl`, existing) and section heading "Opportunities" (`text-xl`, same as existing section titles) | 20px | 600 | 1.2 |

Weights: 400 and 600 only. Do not use `font-medium` and do not use the old `text-3xl` from ProfitSummary (too tall for the compact phone requirement).

## Color

Existing tokens only; light and dark follow `prefers-color-scheme`. No new CSS variables.

| Role | Value | Usage |
|------|-------|-------|
| Dominant (60%) | `--background` | Page |
| Secondary (30%) | `--secondary` | Totals card and graph card surfaces |
| Accent (10%) | `--primary` (#059669 light, #10b981 dark) | See reserved list below |
| Muted | `--muted-foreground` | Labels, captions, counts line text, available figures |
| Destructive | `--destructive` | Not used by the totals card (existing feed load-error alert unchanged) |

Accent reserved for: the Extracted all-time value, the extracted figure in each "Last 7 days / Last 30 days" cell (the primary value), the standard focus ring. Green keeps meaning "extracted", consistent with Phase 6.

Available figures ("Available since Oct 13" value and the "of $X available" captions) use foreground/muted, not green, matching the graph's grey line. The counts-line dollar figures (average, best) use `--foreground` (not green) so accent stays at 10%.

## Interaction Contract

| Interaction | Behavior |
|-------------|----------|
| Totals card | Read-only. No hover, tap, or tooltip behavior. Updates when the feed refetches (Mark done / Undo / odds refresh already bump the response) |
| Graph range picker (7d / 30d / All) | Does not affect the totals card or counts (D-09); the card is always all-time / fixed 7 and 30 day windows |
| Hide / Show graph | Existing behavior, graph card only (D-07) |
| Best promo name | Truncated to one line with ellipsis; full text in the `title` attribute and in an `aria-label` on the line's best-promo span so it is not lost |
| Keyboard / screen reader | Each total cell is a plain `div` with label then value in DOM order (reads "Extracted all-time, $33.09"). Counts line is a single `p` |
| Tab switching | Dashboard panel stays mounted like the other tabs (no refetch on tab switch) |

## Copywriting Contract

Plain English, no jargon, no emoji. All money via `formatUsd` from decimal strings. "Oct 13" is derived from the graph start day, formatted `MMM d`, never hard-coded (D-04).

| Element | Copy |
|---------|------|
| Tab label | `Dashboard` (then Stats, Arbitrage, Promos, Tools) |
| Page heading | `Dashboard` |
| Subtitle | `Your profit so far, and the best money available right now at your books.` |
| Total 1 label | `Extracted all-time` |
| Total 2 label | `Available since Oct 13` |
| Total 3 label | `Last 7 days` ; caption `of $2.56 available` |
| Total 4 label | `Last 30 days` ; caption `of $2.56 available` |
| Counts line | `10 promos done · avg $3.31 each · best $9.05 · DraftKings · College Football 50% Profit Boost` |
| Counts line, singular | `1 promo done · avg $3.31 each · best ...` |
| Best promo when a pair | `best $12.40 · DraftKings + FanDuel pair` |
| Graph headline framing (D-06) | Existing `Extracted $X of $Y available` plus a muted suffix `since Oct 13` for All time; for 7d / 30d ranges the existing range label already frames it. Accessible label unchanged format |
| Feed section heading | `Opportunities` |
| Primary CTA | None. The phase adds no primary action |
| Empty: no promos done | Counts line reads `No promos done yet`; Extracted all-time shows `$0.00` |
| Empty: no member observations yet | `Available since Oct 13` shows `$0.00`; 7d / 30d captions read `of $0.00 available` |
| Empty: observation table unavailable | Available cells show `Not ready yet` (muted, replaces the figure and captions); extracted figures still show. Same wording family as the graph's "Graph not ready yet"; no error styling |
| Error state | If the feed fails to load, the existing `Couldn't load opportunities. Try again in a moment.` alert with `Try again` button covers the screen; the totals card is not rendered. No separate totals error |
| Destructive actions | None in this phase |

Empty-state rule: the totals card always renders when the response is ok, even if the feed is empty (`emptyVariant` set), so the numbers never disappear because the live feed is momentarily empty (same rule ProfitSummary followed).

## Assumptions (not owner-confirmed)

The owner locked D-01..D-17 and picked layout B from mockups (not re-asked). These are defaults for review:

1. Type scale 12 / 14 / 18 / 20 with weights 400 / 600; value size dropped from ProfitSummary's `text-3xl` to 18px so the 2 x 2 phone grid stays compact.
2. Extracted values green (`--primary`), available values neutral, mirroring the graph's green = extracted rule.
3. 7d / 30d captions placed under the value (`of $X available`) rather than inline, so the 2 x 2 cell fits 360px.
4. Counts line items separated by ` · `, singular "1 promo done", and the `Not ready yet` wording for a missing observations table (CONTEXT left the exact wording to discretion).
5. Graph card suffix "since Oct 13" shown only for the All time range; wording of the suffix is a default.
6. Old ProfitSummary footnote ("Best guaranteed profit seen per promo...") is dropped from the Dashboard; the graph caption already explains the rule.
7. Totals card is read-only with no tooltips.
