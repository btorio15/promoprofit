## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| browser → confirm/dismiss actions | Untrusted promoId from any logged-in member |
| stored best_guess (scraper-derived) → activation | A stale or malformed stored guess could activate a wrong promo |

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|

| T-03-07-02 | Tampering | action input | mitigate | PromoIdInputSchema strict positive int; no user field (IDOR), user id only from session |
