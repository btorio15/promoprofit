  <name>Whole-contract market hedge solvers</name>
  <files>src/domain/market/solveMarketHedge.ts, src/domain/market/solveMarketHedge.oracle.ts, src/domain/market/solveMarketHedge.test.ts</files>
  <behavior>
    Core (bookWinsGross G = what the book returns if the book bet wins, cent-floored; bookCashOutlay S = cash staked at the book, 0 for a bonus bet):
    - netIfBookWins(N) = G - S - outlay(N); netIfMarketWins(N) = N - S - outlay(N); maximize min; equal-min tie broken by larger max, then smaller N
    - Example: bonus $50 at +150 (G = 75.00, S = 0), Kalshi YES @ 61c -> N = 75, cost 45.75, fee ceil(0.07*75*.61*.39)= 1.25 (1.248975 up), outlay 47.00, both outcomes 28.00, guaranteedProfit 28.00, conversionPct 56.00
    - Returns null when the best min profit <= 0 or best N < 1
    Bonus: hedgeStake = outlay, hedgePayout = N, bonusPayout = G, netIfBonusWins = G - outlay, netIfHedgeWins = N - outlay, conversionPct = profit / bonus x 100 at 2 dp ROUND_DOWN (match bonusBet.ts precision for conversionPct)
    Boost: identical input validation and D-17 min-odds gate to calculateProfitBoostHedgeUnfiltered; promo stake candidates are the same set (floored max stake, kink floor/ceil when the cap binds) per the Key Decision "boost stake defaults to the max allowed by caps"; for each candidate S, G = floorCents(promoPayoutRaw(S, ...)), solve N; keep the best; hedgeStake = outlay, hedgePayout = N, totalStaked = S + outlay, roiPct = profit / totalStaked x 100 (same rounding as profitBoost.ts), capBound as in the book solver
    Arb: book stake B at precision unit and N contracts with B + outlay(N) <= totalStake; profit = min(floorCents(B x d), N) - B - outlay(N); exact joint search (see implementation); impliedSum = 1/d + outlay/N; returns null when no positive profit
    Oracle equality (profit only, compared as cents):
    - bonus: 2,000 seeded cases (mulberry32 seed 1201): bonus $1..$500 whole, book odds from a grid of +100..+600 and -110..-300, venue random, price 5..95c; oracle scans N in 1..ceil(G)+5
    - boost: 1,000 seeded cases (seed 1202) with maxStake $1..$50 whole, boost % 10..100 on base odds, winningsCap none / net_winnings / total_payout random, precision whole and cents; oracle scans N for each candidate stake from the same candidate rule, computed in integer cents independently (its own floor of stake x rational odds as in noSweat.oracle.ts oddsFraction/floorMulCents)
    - arb: 1,000 seeded cases (seed 1203), totalStake $10..$120 whole, precision whole and cents (cents cases use totalStake <= $15 so the oracle grid stays small); only markets where an arb is possible (1/d + p/100 < 0.99); oracle scans every B unit and every N
    - Edge: priceCents 99 and 1, fee rounding steps (N where Kalshi fee crosses a cent), G an exact integer, G with frac .99
  </behavior>
  <implementation>
    Use a LocalDecimal clone (precision 40) and the clean idiom from bonusBet.ts; all money in Decimal. Never use native float for money (CLAUDE.md); integer arithmetic only in the .oracle.ts file.
    solveMarketHedgeForPayout: profit is nondecreasing in N up to G and nonincreasing beyond (both outcomes subtract the same outlay; RESEARCH Pattern 1), so evaluate N in [floor(G) - 3, ceil(G) + 3] clipped to N >= 1 (Pitfall 4 window for fee-rounding steps); this is exact, and the oracle proves it.
    solveArbWithMarket: N-major scan. For N from 1 while N x priceCents/100 <= totalStake: for fixed N the best book stake is the smallest unit-multiple B with floorCents(B x d) >= N (profit is nondecreasing below it and decreasing above), so evaluate B* = that value and B* - unit, each only if B >= unit and B + outlay(N) <= totalStake. Pre-check: return null immediately unless 1/d + p/100 + r < 1, where r = the unrounded per-contract fee rate coefficient x multiplier x (p/100) x (1 - p/100) from VENUE_FEES (a lower bound on fee per contract, so no real arb is ever skipped), so rankers only pay the scan cost on real arbs. Keep the best by profit, ties by smaller totalLaid then smaller N.
    Oracle file: header like noSweat.oracle.ts; exports bruteForceMarketBonus, bruteForceMarketBoost, bruteForceMarketArb; uses feeCentsOracle from ./fees.oracle and rational odds fractions; returns { profit: Decimal } built only at the boundary.
    RED: write the oracle + test file (table cases above including the worked $50 @ +150 / 61c example), run, must fail; commit test(12-04). GREEN: implement; commit feat(12-04). REFACTOR only if needed.
  </implementation>
