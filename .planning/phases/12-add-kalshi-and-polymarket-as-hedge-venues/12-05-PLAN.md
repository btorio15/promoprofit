  <name>Boost + boost pair with a market top-up leg</name>
  <files>src/domain/market/solvePairMarketTopUp.ts, src/domain/market/solvePairMarketTopUp.oracle.ts, src/domain/market/solvePairMarketTopUp.test.ts</files>
  <behavior>
    - Outcomes with top-up on B's side (N contracts that win when B's side wins), T = sA + sB + outlay(N): A wins -> PA(sA) - T; B wins -> PB(sB) + N - T. Mirror for top-up on A's side.
    - Promo stakes follow the existing boost stake rule per leg (floored max stake, plus kink floor/ceil when the winnings cap binds, clamped to [unit, flooredMax]) — Key Decision "boost stake defaults to the max allowed by caps". For each (sA, sB) candidate pair and each side with a market leg, N is chosen exactly: profit is nondecreasing in N up to the balance point N0 = PA - PB (top-up on B) and nonincreasing beyond, so scan N in [floor(N0) - 3, ceil(N0) + 3] with N >= 1. Skip a side whose N0 < 1 (the top-up would be on the wrong side).
    - Min-odds (D-17) and input validation identical to solveBoostBoostPairWithTopUp (reuse by calling the same exported helpers; do not duplicate a weaker check).
    - Returns the best positive-profit result across both sides; null when none is positive. Ties: larger max outcome, then smaller T, then side "B" before "A".
    - legA/legB carry priceSource and capBound exactly as the book top-up solver reports them; totalStaked includes the market outlay; roiPct = profit / totalStaked x 100 using the pairMath rounding.
    - Oracle equality (profit only): 1,500 seeded cases (mulberry32 seed 1205), maxStakes $1..$40 whole, boosts 10..100% on base odds +100..+300 opposite sides, caps random, market price 20..80c random venue, both precisions; the oracle uses the same candidate stakes and scans N from 1 to ceil(N0) + 10 in integer cents with feeCentsOracle.
    - Bounded-loss property (documents the stake-rule choice): on 300 small whole-dollar cases (seed 1206, maxStakes <= $12), a full grid brute force over every (sA, sB, N) is never better than the solver by more than $1.00.
  </behavior>
