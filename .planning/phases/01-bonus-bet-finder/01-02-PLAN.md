src/db/schema.ts (Drizzle pg-core, all timestamps `{ withTimezone: true }`):

- `cached_odds`: event_id text PK, sport_key text not null, commence_time timestamptz not null, raw_response jsonb not null (one full Odds API event object), fetched_at timestamptz not null; indexes on sport_key and commence_time.
- `credit_usage`: id serial PK, requests_remaining integer not null, requests_used integer not null, refresh_cost integer not null, sports_fetched integer not null, recorded_at timestamptz not null default now(). Plan 04 writes it and Plan 05 reads it; create it now so there is one migration.

src/db/client.ts: `getDb()` is a lazy singleton using `neon(process.env.DATABASE_URL)` + `drizzle({ client, schema })` from "drizzle-orm/neon-http". src/db/queries.ts: implement the four functions in <interfaces>. getCachedEvents parses each raw_response with OddsEventSchema.safeParse, drops (and console.warn's the event_id of) rows that fail, and never throws on one bad row.

src/app/actions/find-hedges.ts ("use server"): findHedges(input: unknown):
1. FinderInputSchema.safeParse; on failure return { status: "invalid", fieldErrors } (flattened).
2. books = getBonusBooks(); if bookKey is not among them, return invalid with the bookKey message (D-14).
3. { events, fetchedAt } = getCachedEvents(); if fetchedAt is null, return { status: "no_cached_odds" }.
4. markets = extractTwoWayMoneylines(events, { now: new Date(), windowDays: 7, allowedBookKeys: new Set(await getHedgeBookKeys()), sportKeys: sportKey === "all" ? new Set(SPORT_KEYS) : new Set([sportKey]) }).
5. rankBonusBetHedges(markets, { bonusBookKey, bonusAmount: new Decimal(bonusAmount), hedgeBookKeys, limit: 10 }).
6. Map each opportunity to FinderResultDTO: every Decimal via `.toFixed(2)`, commenceTime ISO, bookName from the books list, sportLabel via getSportLabel.
7. Return status "ok" with oddsFetchedAt ISO, bonusBookName, and bonusAmount normalized to 2 dp.
Zero Odds API calls on this path (D-13): the file must not import anything from src/ingestion.

scripts/seed.ts: upsert every COLORADO_BOOKS entry into books (onConflictDoUpdate on key). With `--fixtures`, also upsert buildFixtureEvents(new Date()) into cached_odds with fetched_at = now, so the finder works before an Odds API key exists. Log counts. scripts/db-check.ts: prints getBonusBooks() and the count and freshness from getCachedEvents(); exits 1 if there are 0 books.

Run `npm run db:generate` to produce the SQL migration in ./drizzle. Commit it. Use generate + migrate, not push, per CLAUDE.md/RESEARCH.md.
