<objective>
PART 1 of a 3-part split (see the planner's handback): add a "these exact games" promo scope to the data model and make every matching path honor it. No parser or UI changes here -- Part 2 (manual multi-game picker) and Part 3 (parser/reader detection) build on this.

Purpose: today a promo can only be "one game" (event), "any game in a league over a date window" (sport_window) or "any game" (any). A promo good on only "Chiefs @ Bills or Eagles @ Cowboys" has no correct shape, so it is either lost or (worse) stored league-wide and hedged on games it doesn't cover. This plan adds the shape and guarantees a 2-game promo is never hedged on a third game.

Output: new scope kind "games", migration 0017 (generated only), DB read/write mappers, labels, tests. Stake/profit math untouched.
</objective>
