Owner request (verbatim): "set the max bet for every promo at 25 dollars. Users can set their max bets individually by promo, which we already do, or by book in the settings."

Make $25 the default max bet for every profit boost, add a per-member, per-book max bet on the Settings page, and keep the existing per-promo "Your cap". Precedence for a profit boost's effective max stake:

1. Per-promo "Your cap" (existing user_promo_caps) -- wins outright, unchanged behavior (quick-261001-dhn deliberately allows it to be higher than the book page's cap; do not change that).
2. Otherwise the member's cap for that book = per-book Settings value if set, else DEFAULT_MAX_STAKE "25.00" -- and then the LOWER of that and the promo's own cap (promos.max_stake) when the promo has one. The default/per-book value never raises a stake above the book's real cap.

Bonus bets: untouched (their stake is the fixed bonus amount; max bet does not apply -- matches the existing rule that only profit boosts take caps).

Purpose: the group bets $25 boosts by default without having to type a cap on every promo, and can raise/lower that per book once.
Output: domain precedence logic + tests, user_book_caps table + committed migration, server action, Settings UI, updated cap labels on rows.
</objective>
