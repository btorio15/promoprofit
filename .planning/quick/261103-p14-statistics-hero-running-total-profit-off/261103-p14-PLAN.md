# Quick 261103-p14: Statistics hero chart: running total of profit offered

Owner request (2026-11-03): "a big graph on the statistics page, something that is eye catching. Maybe total site profit available." Owner chose: **running total** (each promo counted once) and a **dark hero panel**.

## Definition (locked)
- Source: the daily promo history `getStats` already returns (`stats.history`, rows of promoId / denverDate / profit from `promo_profit_observations`, site-wide scraped promos only).
- Each promo counts **once**: its value is its **highest** recorded daily profit, dated on the **first** Denver date it appeared.
- Series: for each Denver date from the first date in range to the last, the cumulative sum (days with nothing new carry the previous total, so the line is a continuous step-up). Respect the existing range picker (7 days / 30 days / All time): only promos whose first date falls in range, cumulative from 0 at the range start.
- Headline: the final cumulative total, e.g. "$169.01", with a caption "offered across the site since Sep 27 · 44 promos".
- All money in decimal.js; the pure helper returns strings (2 dp); chart y-values may be Number() only for plotting.

## Task 1 (tdd): pure helper `src/domain/stats/runningTotal.ts`
`buildRunningTotal(history, range)` → `{ points: {date: string; total: string; added: string}[]; total: string; promoCount: number; since: string | null }`.
Table-driven tests: one promo seen on 3 days counts once at its max on its first day; gap days carry the total forward; range filter; empty history → total "0.00", points [], since null; cent-exact sums (e.g. 0.1 + 0.2 style values).
