<objective>
Phase goal (user story):

**As a** group member, **I want to** add a promo I see in my own sportsbook app and manage the ones I added, **so that** my Promos list and Opportunities feed include the promos the scrapers miss, with the same exact hedge math, visible only to me.

Management slice (part 3): Done rows know their source's state. A promo the member added and already marked done keeps its Done row and its profit in Total profit extracted even after it is deleted (D-11); while the source is still active or expired the member can expire/delete it from the Done row; once deleted the row shows no actions but keeps its "Added by you" badge. Resolves Research Open Question 3.

Purpose: PROMO-05 (manage from Done, history preserved), D-11.
Output: completion query + DTO fields with tests, Done-row badge and actions.

Discretion (documented, carried from Plan 07): Done rows show Expire now / Delete but not Edit (a done promo's snapshot is frozen and it is not in the feed).
</objective>
