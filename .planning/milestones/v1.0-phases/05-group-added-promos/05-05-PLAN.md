<objective>
Phase goal (user story):

**As a** group member, **I want to** add a promo I see in my own sportsbook app and manage the ones I added, **so that** my Promos list and Opportunities feed include the promos the scrapers miss, with the same exact hedge math, visible only to me.

UI half of the first add slice: a member taps "Add promo" at the top of Promos > Active, enters a bonus bet (book, amount, expiry, optional game(s) and min odds), saves, and immediately sees it ranked in their Promos and Opportunities with the exact existing bonus-bet hedge math, marked "Added by you". The server contract (addPromo, getAddPromoFormOptions, schemas) comes from Plan 04. The profit-boost type (and the Type toggle) arrives in Plan 06.
