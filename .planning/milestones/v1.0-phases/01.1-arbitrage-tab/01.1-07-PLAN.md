- Guard against out-of-order responses with a request counter held in a ref. Only the latest request may set the response.

- A Skeleton (three h-14 bars) while pending with no previous ok response.

- The button is disabled when status.level === "blocked", or status.remaining is not null and below status.estimatedExtendedRefreshCredits, or a search is pending. This is UX only: the server re-gates.
