**Analog:** `src/domain/hedge/bonusBet.ts` (entire file, 122 lines — small file, read in full)

**Precision-clone + truncation-noise discipline** (lines 26-39):
```typescript
// Local clone so this module never mutates the shared global Decimal config.
const LocalDecimal = Decimal.clone({ precision: 40 });

// American odds like -300 (1 + 1/3) or -275 (1 + 4/11) have no exact base-10
// representation, so every division/multiplication through them carries an
// unavoidable truncation of a few units in the ~38th-40th decimal place
// (see americanOdds.ts)... Snapping to 20 decimal places with normal
// rounding erases that noise... while leaving genuine sub-cent content
// untouched.
function clean(value: Decimal): Decimal {
  return value.toDecimalPlaces(20, Decimal.ROUND_HALF_UP);
}
```
Copy this `LocalDecimal` clone + `clean()` helper verbatim into `arbMath.ts` — RESEARCH.md's `## Arb Math` section explicitly calls out reusing this exact discipline since American-odds decimal conversions carry the same base-10 truncation noise here.

**Rounding-candidate-and-maximize pattern, generalized to two legs** (lines 75-105, and RESEARCH.md's `## Arb Math` code block):
```typescript
const roundedCandidates = [
  hedgeStakeExact.toDecimalPlaces(2, Decimal.ROUND_DOWN),
  hedgeStakeExact.toDecimalPlaces(2, Decimal.ROUND_UP),
];
const candidateStakes = roundedCandidates.filter(
  (stake, index) => roundedCandidates.findIndex((other) => other.equals(stake)) === index,
);

let best: Candidate | null = null;
for (const hedgeStake of candidateStakes) {
  const hedgePayout = clean(hedgeStake.times(hedgeDecimalOdds)).toDecimalPlaces(2, Decimal.ROUND_DOWN);
  const netIfBonusWins = bonusPayout.minus(hedgeStake);
  const netIfHedgeWins = hedgePayout.minus(hedgeStake);
  const guaranteedProfit = Decimal.min(netIfBonusWins, netIfHedgeWins);
  const isBetter = best === null || guaranteedProfit.gt(best.guaranteedProfit) || /* tiebreak */;
  if (isBetter) best = { hedgeStake, hedgePayout, netIfBonusWins, netIfHedgeWins, guaranteedProfit };
}
```
`arbMath.ts` extends this to a 2×2 (deduped) candidate grid over two independently-rounded legs — RESEARCH.md's `splitArbStake` function is the concrete target shape (see `01.1-RESEARCH.md` `## Arb Math`, lines ~345-374 as read in this session): try floor/ceil on **both** `stakeA` and `stakeB` independently, keep whichever pair maximizes `Decimal.min(netIfAWins, netIfBWins)`. Do NOT derive `stakeB = total - stakeA_rounded` (Anti-Pattern explicitly called out in RESEARCH.md).

```typescript
export function findBestArbPair(
  sideAQuotes: SideQuote[],
  sideBQuotes: SideQuote[],
): BestArbPair | null {
  let best: BestArbPair | null = null;
  for (const a of sideAQuotes) {
    for (const b of sideBQuotes) {
      if (a.bookKey === b.bookKey) continue; // D-06: different books required
      const impliedSum = new Decimal(1).dividedBy(americanToDecimal(a.oddsAmerican))
        .plus(new Decimal(1).dividedBy(americanToDecimal(b.oddsAmerican)));
      if (best === null || impliedSum.lt(best.impliedSum)) {
        best = { sideA: a, sideB: b, impliedSum, tiedBooksA: [], tiedBooksB: [] };
      }
    }
  }
  if (best === null) return null;
  best.tiedBooksA = sideAQuotes.filter((q) => q.bookKey !== best!.sideA.bookKey && q.oddsAmerican === best!.sideA.oddsAmerican).map((q) => q.bookKey);
  best.tiedBooksB = sideBQuotes.filter((q) => q.bookKey !== best!.sideB.bookKey && q.oddsAmerican === best!.sideB.oddsAmerican).map((q) => q.bookKey);
  return best;
}
```
D-04/D-05 ("every true arb above 0%, no near-arbs") is then just `impliedSum.lt(1)` — no epsilon, no threshold.
