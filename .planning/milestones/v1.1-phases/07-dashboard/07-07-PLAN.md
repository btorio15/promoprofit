# Plan 07-07: Phone-fit gap closure

## Gaps (Playwright check at 360x780 on betmargin.vercel.app, 2026-10-17)

1. **Tab bar overflow (STATS-07):** the tab list is ~418px wide on a 360px screen, so the whole page scrolls sideways and "Tools" is cut off.
2. **First opportunity too far down (success criterion 5):** with the graph hidden, the "Opportunities" heading sits at ~888px on a 780px screen. Contributors: totals card 275px tall ("Available since Oct 13" wraps), 32px gaps between every block, 78px collapsed graph bar.
3. **WR-01:** the graph's 7d/30d ranges are clamped to the graph start day but show no "since" label, so their headline can differ from the totals card with no explanation.
4. **WR-02:** the headline's `aria-label` overrides its visible text, so screen readers never hear "since Oct 13".

## Tasks

- Wrap the `TabsList` in `AppShell.tsx` in a horizontal scroll container (`-mx-4 overflow-x-auto px-4`, hidden scrollbar, bottom padding so the active underline is not clipped).
- Trigger text `text-[13px] sm:text-sm` so more tabs fit on a phone.
- Done when: at 360px `document.documentElement.scrollWidth === 360` and every tab is reachable.

### Task 2: Shorter totals card and tighter Dashboard stack

- `ProfitGraph.tsx`: collapsed "Show graph" bar uses `py-2` instead of `p-4` vertical padding.
- Done when: graph hidden at 360x780, the "Opportunities" heading and Sort row are on the first screen.

### Task 3: Graph "since" label follows the clamp (WR-01, WR-02)
- `profitGraphView.ts`: `sinceLabel` is set whenever the range start equals `graphStartDay` (All, or 7d/30d clamped); null otherwise. `ariaLabel` appends the since label when present.
- Update `profitGraphView.test.ts`: clamped 7d/30d get "since Oct 13"; an unclamped 7d stays null; aria label includes "since Oct 13".
